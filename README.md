# Mohammad Ali Noman Reza — Academic Portfolio (multi-page)

**Live website after upload:** https://nomanreza-academic.github.io/

## Upload to GitHub Pages
1. Extract this ZIP file.
2. Open https://github.com/nomanreza-academic/nomanreza-academic.github.io
3. Upload **the files and folders INSIDE** this ZIP to the repository root on the `main` branch. Do not upload the ZIP itself or nest everything within another folder. Replace old files. In particular, upload `index.html`, `.pages.yml`, `assets/`, `data/`, `media/` and the page folders (`about/`, `research/`, etc.).
4. GitHub **Settings → Pages**: deploy from `main` and `/(root)`.
5. When the deployment finishes, open the website. Hard refresh with Ctrl+Shift+R if needed.

## Edit with Pages CMS (no coding)
1. Sign in at https://app.pagescms.org with GitHub and choose this repository.
2. Edit **Homepage, about and contact**, **Research projects**, **Publications**, **Teaching and supervision**, **Education**, or **Videos**.
3. Save: Pages CMS commits changes to GitHub, and GitHub Pages republishes the site.
4. For video: open **Videos**, add an entry, and paste a `youtube.com/watch?v=...`, `youtu.be/...`, `youtube.com/shorts/...` link. Videos appear embedded on `/videos/`. For small locally hosted videos, upload MP4 in `media/videos/` and set `video_url` to `/media/videos/FILENAME.mp4`.
5. Update portrait: upload a photo under **Photos** and select it under **Homepage, about and contact → Portrait photo**. The included image is `/media/portrait.jpg`.
6. Update CV: upload PDF under **Documents and CV** and select it under **Homepage, about and contact → CV PDF**.

- Google Scholar and LinkedIn fields remain blank until verified.
- All URLs use root-relative paths and are intended for the username Pages site above.
- GitHub may not show empty folders, so this ZIP includes `.gitkeep` in optional media subfolders.
- **Do not upload files containing sensitive information.** Review the included public CV and contact details before publishing.
- Do not use GitHub as a large-video streaming host; YouTube embeds are preferred.
